### UJ-14 — Hapus peminjaman, detail ikut terhapus (positif)
```sql
INSERT INTO peminjaman (kode_peminjaman, id_anggota, id_petugas, tanggal_pinjam, tanggal_jatuh_tempo, status_pinjam)
VALUES ('PMJ-UJI-02',
        (SELECT id_anggota FROM anggota WHERE nomor_anggota = 'AGT-0002'),
        (SELECT id_petugas FROM petugas WHERE username = 'siti.np'),
        '2026-11-04', '2026-11-11', 'dipinjam');
INSERT INTO detail_peminjaman (id_peminjaman, id_buku, jumlah)
VALUES ((SELECT id_peminjaman FROM peminjaman WHERE kode_peminjaman = 'PMJ-UJI-02'),
        (SELECT id_buku FROM buku WHERE isbn = '9786230020035'), 2);

SELECT COUNT(*) AS detail_sebelum FROM detail_peminjaman
WHERE id_peminjaman = (SELECT id_peminjaman FROM peminjaman WHERE kode_peminjaman = 'PMJ-UJI-02');

DELETE FROM peminjaman WHERE kode_peminjaman = 'PMJ-UJI-02';

SELECT COUNT(*) AS detail_sesudah FROM detail_peminjaman
WHERE id_peminjaman NOT IN (SELECT id_peminjaman FROM peminjaman);
```
Harapan: `detail_sebelum` = 1 dan `detail_sesudah` = 0.

### UJ-17 — Jumlah melebihi stok (uji gagal)
```sql
START TRANSACTION;
UPDATE buku SET stok = 2 WHERE isbn = '9786230010011';
INSERT INTO detail_peminjaman (id_peminjaman, id_buku, jumlah)
VALUES ((SELECT id_peminjaman FROM peminjaman WHERE kode_peminjaman = 'PMJ-UJI-16'),
        (SELECT id_buku FROM buku WHERE isbn = '9786230010011'), 5);
SELECT stok FROM buku WHERE isbn = '9786230010011';
ROLLBACK;
```
Harapan awal: ditolak karena 5 > 2. **Perkiraan hasil: diterima**; `ROLLBACK` mengembalikan data seperti semula.
